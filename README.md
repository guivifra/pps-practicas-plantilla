# Prácticas — Puesta en producción segura

Este repositorio contiene las prácticas, documentos y evidencias del
alumnado del módulo **Puesta en producción segura**.

## Cómo usar este repositorio

1. Crea tu propio repositorio privado desde esta plantilla.
2. Clona tu repositorio:

```bash
git clone [https://github.com/TU-USUARIO/TU-REPOSITORIO.git](https://github.com/TU-USUARIO/TU-REPOSITORIO.git)
cd TU-REPOSITORIO
```

3. Trabaja en una rama para cada práctica:

```bash
git switch -c practica/ud3-1-analisis
```

4. Guarda los documentos en `docs/`.
5. Guarda capturas, registros y otras evidencias en `evidencias/`.
6. Haz commits pequeños y descriptivos.
7. Abre una Pull Request hacia `main` cuando termines la práctica.

## Estructura

```text
docs/
├── ud1/
├── ud2/
└── ud3/

evidencias/
├── ud1/
├── ud2/
└── ud3/
```

## Reglas

- No subas contraseñas, tokens, claves privadas ni datos personales.
- No subas imágenes enormes: usa capturas en PNG o JPG.
- Usa nombres de archivo en minúsculas y con guiones.
- Cada práctica debe tener su propio archivo de entrega.
- No modifiques el workflow de seguridad.
